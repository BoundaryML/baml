## Get started in minutes.

Start with the traces you already have, and add BAML when you want richer data.

1. **Send your traces.** Point your existing OTLP exporter at Boundary. Book a meeting, and we'll set it up with you.
2. **Query them with SQL.** Run SQL over every call from Studio, the baml query CLI, or HTTP.
3. **Build your tools.** Turn a query into a dashboard in Studio, or have your coding agent wire it into Slack, GitHub Actions, or your admin panel.
4. **Add BAML for richer data.** Move one AI function into BAML. Each call then records its typed result, the step that failed, and the code version.

## The all-in-one toolchain for agents.

Existing languages leave you hanging once you want to deploy to production. There is no unified toolchain to debug issues in production.

BAML is the language for programs and their data.

- A sound type system, like Rust
- Fast compilation times, like Go
- Low-cost telemetry, built into the runtime
- Built-in AI capabilities
- Fully integrated with Boundary Cloud (or bring your own)
- Cross-compatible with Python, TypeScript, Rust, and more
