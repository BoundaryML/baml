## One API, for every use case.

Every tool starts with the same call: SQL over everything your program recorded. Run it in your terminal, from a dashboard, or have your coding agent write it.

Each use case shows its query, a switch between **Terminal** (`baml query`) and **Dashboard** (`boundary.query`), and what it builds. The use cases change every 5 seconds until someone clicks one, and pause while hovered. The pictures use example data. Then "Or anything else your team needs."

- **Alerts (Slack alert).** Post to Slack when a function starts failing.
- **Dashboards (Custom dashboard).** Track latency and volume for every function.
- **AI evals (Test cases).** Turn failed production calls into test cases for your next change.
- **User funnels (User funnel).** See where new users drop off on the way to their first result.
- **Cost by customer (Usage report).** See input and output tokens for each customer, from the metadata you attach to each call.
- **Model testing (Model comparison).** When a model ships, have an agent run your evals against it and compare the results.

## Get started in minutes.

Start with the traces you already have, and add BAML when you want richer data.

1. **Send your traces.** Point your existing OTLP exporter at Boundary. Book a meeting, and we'll set it up with you.
2. **Query them with SQL.** Run SQL over every call from Studio, the baml query CLI, or HTTP.
3. **Build your tools.** Turn a query into a dashboard in Studio, or have your coding agent wire it into Slack, GitHub Actions, or your admin panel.
4. **Add BAML for richer data.** Move one AI function into BAML. Each call then records its typed result, the step that failed, and the code version.

## The all-in-one toolchain for agents.

Existing languages leave you hanging once you want to deploy to production. There is no unified toolchain to debug issues in production.

BAML is the language for programs and their data.

- A sound type system, like Rust
- Fast compilation times, like Go
- Low-cost telemetry, built into the runtime
- Built-in AI capabilities
- Fully integrated with Boundary Cloud (or bring your own)
- Cross-compatible with Python, TypeScript, Rust, and more
