# GitHub issue: https://github.com/BoundaryML/baml/issues/4377

Author: @BenSpex

> We currently ship a `[patch.crates-io]` onto a vendored copy with the two features removed.

- [ ] Post after publication checks pass and notification sending is authorized.
- Comment URL: pending.

```text
Thank you @BenSpex for tracing the workspace-wide serde_json feature changes. BAML 0.25.0 gives baml_bridge its own serde_json dependency without forcing arbitrary_precision or preserve_order. You can remove the bridge-only vendored patch after updating the generated SDK and bridge together. If your application needs those features, enable them explicitly on your own serde_json dependency. This changes JSON object ordering and handling of integers beyond i64/u64 when those features are otherwise absent; BAML map insertion order is unchanged. Release notes and migration details: https://boundaryml.com/changelog.
```
