# Hello. And メェー!

Welcome to [BAML](https://boundaryml.com)! We're so glad you're here to learn with us!

BAML is a simple but powerful language for building
[high-performance](https://www.boundaryml.com/blog/sota-function-calling)
AI prompts.

It's true that BAML is a new language, and who wants to learn
a new language? Well, our proposition to you is that LLMs are
so different from the rest of application development, that if
you try to interface with them through existing tools, it will feel
like pushing square pegs through round holes.

So BAML was designed to wrap LLMs simply and easily, bridging the gap
between this alien technology and the familiar tools use already use
for building web applications.

So invest a little time with this interactive guide. Bootstrap an app with our
helpful [chatbot](https://chat.boundaryml.com). Dive into the
[official docs](https://docs.boundaryml.com). You'll find the language
is small and simple, but that this really is the right way (and the fun way)
to build an app around LLMs!

Click the `>` button at the bottom of the page to get started!
