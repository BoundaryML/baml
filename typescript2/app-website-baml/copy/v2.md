# The programming language for agents.

BAML is a language for writing AI agents, with efficient built-in telemetry. BAML builds a database of your program's executions that you can query locally (or in the cloud) to build anything: evals, cost alerts, error tracking, and more.

**Install BAML** · Explore BAML, the install panel, and the code editor.

Diagram: **Your program** (Agents and AI functions, written in BAML.) → **Recorded** (Every execution, by the runtime itself.) → **baml query** (SQL, locally or in the cloud.) → **Anything** (Evals, cost alerts, error tracking, and more.) The query types itself, picks out pixels in the record, and lights one output: Evals, Cost alerts, or Error tracking.
