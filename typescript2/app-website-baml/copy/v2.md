# The programming language for agents.

Rust-like types · Go-like compile times · SQL-queryable telemetry

BAML is a language for writing AI agents, with efficient built-in telemetry. BAML builds a database of your program's executions that you can query locally (or in the cloud) to build anything: evals, cost alerts, error tracking, and more.

**Install BAML** · Explore BAML. The hero no longer has the code editor or the install panel.

Diagram: **Your program** (Agents and AI functions, written in BAML.) → **Recorded** (Every execution, by the runtime itself.) → **baml query** (SQL, locally or in the cloud.) → **Anything** (Evals, cost alerts, error tracking, and more.) The query types itself, picks out pixels in the record, and lights one output: Evals, Cost alerts, or Error tracking.

## Build anything.

In BAML, an agent is an ordinary program, with loops, branches, tools, and model calls in one language.

- **Self-improving agent.** Queries its own failed calls with baml query, turns them into test cases, rewrites its prompt, and keeps the change only if the tests pass.
- **Claude Code with approved tools.** Runs Claude Code from a BAML function with only the tools you allow, and returns a typed result.
- **CI fixer.** When CI fails, reads the log, fixes the code on a branch, runs baml test, and opens a pull request.
- **Parallel code review.** Spawns security, performance, and correctness reviewers on one diff, then merges their typed findings into one report.
- **Incident responder.** Starts from an alert, reads logs and metrics through MCP tools, and posts a typed root-cause report to Slack.
- **Database agent with approvals.** Reads data through a read-only SQL tool. Any write waits for a person to approve it, in ordinary code.
