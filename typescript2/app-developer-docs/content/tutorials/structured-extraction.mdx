## What you will build

Extract a list of items and a nullable total from receipt text. Create a [Canary project](/baml/get-started) first. You need an OpenAI API key to run the model call; the TypeScript option also needs Node.js.

## 3. Call the client

Set the API key and try the function from the project root:

```sh
export OPENAI_API_KEY="your-api-key"
baml check
baml run extract_receipt -- --text 'Coffee x2 $3.00 each. Total $6.00.'
```

To call it from Node.js, [generate the TypeScript SDK](/baml/bridges/typescript#generate-the-sdk), then use the async export from server-side application code:

```typescript
import { extract_receipt_async } from "./baml_sdk/index.js"

export async function extractReceipt(text: string) {
  const receipt = await extract_receipt_async(text)

  return {
    lineItems: receipt.items.length,
    total: receipt.total ?? null,
  }
}
```

## 4. Add tests and handle missing data

- Add representative tests for clean, noisy, and incomplete receipts.
- Decide whether a missing total is acceptable before making it optional.
- Keep credentials and model calls in server-only modules.
- Regenerate the client whenever the result model changes.

Review the [TypeScript bridge](/baml/bridges/typescript) for host-language details, or open the [function reference](/baml/language/functions) for the syntax.
