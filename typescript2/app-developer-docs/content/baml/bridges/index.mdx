## The bridge contract

Generate an SDK when your application needs to call BAML functions. The SDK maps BAML types to host-language types and uses a runtime package to execute the calls.

## Host languages

Start with the TypeScript guide below. For other generators available in your installed toolchain, run `baml generate add --help`.
