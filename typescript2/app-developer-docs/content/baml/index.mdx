Write functions, prompts, and data models in BAML. Run them directly with the CLI, or generate an SDK to call them from your application. Functions can call models, transform data, handle errors, and run work concurrently.

## Open language

BAML is open source. Read the [compiler and runtime source](https://github.com/BoundaryML/baml), report bugs, or contribute changes.

## Start learning

[Install Canary and run a function](/baml/get-started), then read the [BAML book](/baml/book).

## Reference

Look up declaration syntax in the [language reference](/baml/language) and library APIs in [standard packages](/baml/packages). Select your toolchain version when checking a library API.

## Language bridges

[Generate an SDK](/baml/bridges) to call BAML functions from your application.
