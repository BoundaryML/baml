## Variables

<PerspectiveNote kind="same" summary="Type inference, reassignment, and block scope">


</PerspectiveNote>

## Numbers

BAML splits TypeScript's `number` into `int` for integers and `float` for floating-point values.

| TypeScript | BAML | BAML result |
| --- | --- | --- |
| `285 / 100` | `285 / 100` | `2` (integer division) |
| `285 / 100` | `285 / 100.0` | `2.85` |
| `2 === 2.0` | `2 == 2.0` | `false` (different types) |
| `2 < 2.5` | `2 < 2.5` | Compile error: types must match |
| `2 ** 10` | `2.pow(10)` | `1024` |

- A `float` annotation doesn't convert an integer. Use `285 / 100.0`.
- Integers range from −2⁶² to 2⁶²−1. Overflow panics.
- Division by zero panics for both numeric types.

</PerspectiveSection>

<PerspectiveNote kind="same" summary="Floating-point rounding">

`0.1 + 0.2` produces `0.30000000000000004` in both languages.

</PerspectiveNote>

<span id="strings-and-booleans" />

## Strings

<PerspectiveNote kind="same" summary="Double quotes, backticks, and escapes">

```typescript
"Hello\nworld"         // Newline
`Hello ${name}`        // Interpolation
"Hello ${name}"        // Literal text
```

</PerspectiveNote>

<PerspectiveNote kind="modified" summary="String operations">

BAML calls `.length()` and uses interpolation to combine text with numbers.

| TypeScript | BAML |
| --- | --- |
| `text.length` | `text.length()` |
| `"cost: " + cents` | `` `cost: ${cents}` `` |

</PerspectiveNote>

<PerspectiveNote kind="removed" summary="Single-quoted strings">

BAML doesn't accept single-quoted strings; use double quotes or backticks.

</PerspectiveNote>

<PerspectiveSection kind="modified">

## Booleans

BAML uses `bool` and has one pair of equality operators: `==` and `!=`.

| TypeScript | BAML |
| --- | --- |
| `boolean` | `bool` |
| `a === b` | `a == b` |
| `a !== b` | `a != b` |

</PerspectiveSection>

## Blocks

BAML blocks produce a value from their final expression. This lets you compute a value in several steps and keep temporary variables local, without creating and calling an extra function.

<CodeComparison from="TypeScript">
<div>

```typescript
const remaining = (() => {
  const limit = 8_000; // Block-local
  return limit - 512; // Returns 7488
})();
```

</div>
<div>

<BamlProject id="listing-03-12" file="baml_src/main.baml" regions={["block-expression"]} />

</div>
</CodeComparison>

### Early returns

A final expression gives the block a value and execution continues. An explicit `return` exits the enclosing function, even from inside a block.

<BamlProject id="listing-03-12" file="baml_src/main.baml" regions={["early-return"]} />

`budget(true)` returns `0`; `budget(false)` continues after the block and returns `8000`. In the TypeScript example above, `return` exits only the immediately invoked arrow function.

</PerspectiveSection>

## AI functions

<BamlProject id="listing-03-06" file="baml_src/main.baml" regions={["client", "summarize"]} />

- `summarize(text)` calls the model and returns a `string` inside BAML.
- `summarize@parse(response)` parses supplied text without a model call.
- `summarize@render_prompt(text)` renders messages without a model call.

Model calls need provider credentials. For concurrent calls, use [spawn and await](/baml/book/concurrency).
