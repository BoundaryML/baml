# @boundaryml/baml-node

Node.js / TypeScript bindings for the BAML runtime (powered by
[`bex_engine`](https://github.com/BoundaryML/baml)).

`@boundaryml/baml-node` is the bridge layer that generated `baml_sdk/`
packages import at runtime: it provides the `BamlRuntime` singleton, the
protobuf encoder/decoder, the function/method factories, and the
`Collector` / `CtxManager` observability primitives.

```ts
import { BamlRuntime } from '@boundaryml/baml-node';

BamlRuntime.initializeRuntime('.', {
    'main.baml': "function ReturnOne() -> int { 1 }\n",
});
```

This package is generally consumed indirectly via the code generated by
`baml-cli generate --output_type nodejs/typescript` — direct use is
reserved for runtime authors and bridge tests.

See the full docs at <https://docs.boundaryml.com>.

## Requirements

- Node.js 18+
- One of the supported platforms: Linux x64/arm64 (glibc + musl),
  macOS x64/arm64, Windows x64/arm64.
