contract evidence for gates B5, B6, and B10. It exercises optionality versus
nullability, semantic partial state, immutable requests/clients/media,
SafeHandle ownership, every dynamic value kind and descriptor identity,
canonical generic binding, generated-code registration, owned collections and
bytes, exact numeric boundaries, explicit unsupported CLR shapes, cycles, and
all frozen managed graph limits.

These definitions are compiled design evidence, not the final runtime package.
Existing probes remain authoritative for unions through arity 32, the
generated V1 seam, exception/cancellation identity, native media restoration,
stream lifecycle, and program/native bootstrap.
