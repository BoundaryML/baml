### `media_url_resolver`

Controls how media URLs are processed before sending to the provider. This allows you to override the default behavior for handling images, audio, PDFs, and videos.

```baml
client<llm> MyClient {
  provider openai
  options {
    media_url_resolver {
      image "always"      // Options: always | never | ensure_mime | if_google_uri
      audio "never"
      pdf "ensure_mime"
      video "never"
    }
  }
}
```

#### Options

Each media type can be configured with one of these modes:

- **`always`** - Always download URLs and convert to base64 data URIs
- **`never`** - Pass URLs through unchanged to the provider
- **`ensure_mime`** - Ensure MIME type is present (may require downloading to detect)
- **`if_google_uri`** - Only process non-gs:// URLs (keep Google Cloud Storage URLs as-is)

#### Provider Defaults

If not specified, each provider uses these defaults:

| Provider | Image | Audio | PDF | Video |
|----------|-------|-------|-----|-------|
| OpenAI | `never` | `always` | `never` | `never` |
| Anthropic | `never` | `never` | `always` | `never` |
| Google AI | `if_google_uri` | `never` | `never` | `never` |
| Vertex AI | `ensure_mime` | `ensure_mime` | `never` | `never` |
| AWS Bedrock | `always` | `always` | `always` | `never` |
| Azure OpenAI | `never` | `always` | `never` | `never` |

#### When to Use

- **Use `always`** when your provider doesn't support external URLs and you need to embed media content
- **Use `never`** when your provider handles URL fetching and you want to avoid the overhead of base64 conversion
- **Use `ensure_mime`** when your provider requires MIME type information (e.g., Vertex AI)
- **Use `if_google_uri`** when working with Google Cloud Storage and want to preserve gs:// URLs

<Warning>
  URL fetching happens at request time and may add latency. Consider caching or pre-converting frequently used media when using `always` mode.
</Warning>
