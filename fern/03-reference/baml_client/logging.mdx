## Logging and Environment Variables

BAML uses the `BAML_LOG` environment variable to determine the logging level.

The default logging level is `INFO`.

The following logging levels are supported:

- `ERROR`
- `WARN`
- `INFO`
- `OFF`

You can also set the logging level using the `set_log_level` function.

<CodeBlocks>
```python
from baml_client.logging import set_log_level

set_log_level("INFO")
```

```typescript
import { setLogLevel } from 'baml-client'

setLogLevel("INFO")
```

## Environment Variables

BAML loads environment variables from the current process's environment.

### Modifying environment variables

If you need to load environment variables from a different source, you can use the `reset_baml_env_vars` function.

<CodeBlocks>
```python
from baml_client import reset_baml_env_vars
import os

reset_baml_env_vars(os.environ.copy())
```

```typescript
import { resetBamlEnvVars } from 'baml-client'

resetBamlEnvVars(process.env)
```
