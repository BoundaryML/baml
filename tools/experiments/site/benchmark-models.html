Can models learn BAML from describe alone?

Six models received an empty project, a writing tool, and the real baml describe command as their only language documentation. None produced a project that compiled.

The valid score is adherence gated by compilation. A fluent non-program scores zero. “Slop” counts evidence-verified findings that survived the skeptic pass.

The result

There is no winner. Claude Sonnet came closest, ending with three compiler errors. Haiku was recognizably BAML-shaped but never checked its final file. GPT-5.1 and GPT-5 Mini committed early to coherent languages of their own invention. Opus and GPT-5 Nano never crossed from reading into writing.

Intentionbench still assigned scores above five to both invalid projects. That is useful evidence about the grader: adherence measures whether source text resembles the design, not whether the source is executable. Compilation therefore remains a hard gate, not another weighted feature.

Model notes

Method

  1. Give every model the same receipt-extractor task and an empty anchored BAML project.
  2. Expose typed actions for describe, file writes, formatting, checks, and tests—no shell.
  3. Limit each builder to twelve turns and 2,048 output tokens per turn; Opus received eight turns to remain under budget.
  4. Run an independent baml check and test pass after the builder stops.
  5. Grade every non-empty project with the same 127-card intentionbench catalog.
