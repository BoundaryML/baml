baml experiments

We co-design BAML with the agents and people who write it. That means running experiments instead of arguing from taste: put models in front of the language, measure what they do, change the language when the data says to. This page collects the runs, with receipts.

Which models write real BAML?
5 models · 127 design-principle cards · one surprise

Five models built the same small BAML project from nothing, learning the language through the CLI. We graded every project against design principles distilled from all 50 BEPs. The best adherence score went to a project that doesn't compile.

 Tool calling for gpt-realtime: baml vs native
19/19 vs 17/19 · live sessions · three suites

Two identical voice sessions, one difference: who turns your words into a tool call. The native lane uses JSON-schema tools in the realtime session. The baml lane delegates to a typed BAML function. The two failures tell you more than the seventeen passes.

Data lives in the experiments Convex project. Graders, harnesses, and raw runs are in the repo under tools/experiments/ and tools/baml-bench/.
