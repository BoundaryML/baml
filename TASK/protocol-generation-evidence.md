## Protocol behavior

The Release behavior probe parses the exact 40-byte Rust-produced
literal-union envelope, validates its selected-arm metadata, and rejects a
contradictory arm. Separately,
`bridge_ctypes::value_encode::tests::emit_csharp_optional_host_call_vectors`
builds five calls through the production Rust `build_to_host_call` encoder and
writes their Prost bytes. The C# probe parses those bytes, binds them into
declaration-order optional slots, executes six malformed-message rejection
branches, and checks the exact BAML integer domain including nested paths.
Both the required callback integer and a present optional callback integer
now pass through the same checked callback decoder, which delegates to the
canonical outbound BAML-int decoder. Four legal callback boundary cases
exercise the exact minimum and maximum through both positions. Twelve
fail-closed cases exercise minimum-minus-one, maximum-plus-one,
`long.MinValue`, and `long.MaxValue` through both positions plus missing and
wrong-oneof carriers in both positions; the probe asserts that none invokes
the host callback.
The five-line Rust vector SHA-256 is
`8950193938db37064a5488edf237a04ba817470b1651e8185d247b3aaadcedf5`.
Exact output:

```text
exact_literal_union_decode=ok
wire_bytes=40
contradictory_metadata=rejected
optional_callback_slots=5/5
malformed_optional_callback_slots=6/6
callback_baml_int_valid=4/4
callback_baml_int_rejected=12/12
callback_baml_int_fail_closed=ok
rust_produced_optional_callback_slots=5/5
baml_int_vectors=encode_decode_checked
```

The malformed set is missing required, required marked optional, unknown
name, duplicate name, wrong first-argument type, and null supplied to the
nonnull later slot. This proves that the negative branches execute; they are
not merely present as unused helper code.
