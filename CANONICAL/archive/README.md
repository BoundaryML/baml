# Project Studio source archive

This directory contains the historical source corpus that previously lived in the repository-root source folder. It was moved under **CANONICAL/archive** on 2026-08-10 so the active design and its provenance remain together.

The active authority is [Project Studio](../README.md) and the [design map](../design/README.md). Documents here are historical inputs, not current decisions. When an archived document conflicts with the active design, the active design wins.

During the move, references to files that exist in this archive were normalized to their new location. References to older source files that were already absent are described as missing historical sources rather than treated as live paths. No substantive design decision was changed by the relocation.
